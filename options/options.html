About

AdBlock Pro
v1.0.0
A high-performance, open-source ad blocker built on Manifest V3.
Compatible with Chrome, Edge, and Firefox.
✓ Network-level ad blocking via declarativeNetRequest
✓ YouTube pre-roll & mid-roll ad removal
✓ Cosmetic filtering with MutationObserver
✓ Anti-fingerprinting (canvas, audio, WebGL)
✓ Popup & redirect protection
✓ Custom EasyList-style user rules
